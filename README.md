# Student Registration Form

A simple HTML/CSS/JavaScript form for registering student details, with a live preview of submitted information.

## Features

- Input fields for student name, course, year level, section, and email
- Client-side validation (all fields required before submission)
- Preview section that displays submitted data
- Clear button to reset the form and preview

## Files

- `index.html` — form markup
- `style.css` — styling for the form and preview section
- `script.js` — form validation and preview rendering logic

## Usage

Open `index.html` in a browser. Fill in the fields and click **Submit** to see the preview, or **Clear** to reset the form.
